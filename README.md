# 생명을 향한 여정 — GitHub Pages 게임

별도 서버, 데이터베이스, 외부 라이브러리 없이 실행되는 단일 페이지 게임입니다.

## GitHub Pages 배포 방법
1. GitHub에서 새 저장소(repository)를 만듭니다.
2. `index.html` 파일을 저장소 최상위(root)에 업로드합니다.
3. 저장소의 **Settings → Pages**로 이동합니다.
4. **Deploy from a branch**를 선택합니다.
5. Branch는 `main`, 폴더는 `/ (root)`를 선택하고 Save를 누릅니다.
6. 잠시 후 표시되는 `https://계정명.github.io/저장소명/` 주소로 접속합니다.

## 파일 구성
- `index.html` : 게임 전체(화면 디자인, 스토리, 선택지, 결과)를 포함합니다.

## 수정할 때
- 스토리/선택지는 `index.html` 안의 `const stages = [...]` 부분에서 수정할 수 있습니다.
- 마지막 결과 문구는 `finish()` 함수 안에서 수정할 수 있습니다.
- 현재 스토리는 전시 체험을 위한 가상 시나리오입니다. 실제 환자 사례, 병원 운영 정보, 진료비를 반영하려면 HMC의 확인을 거쳐 문구를 업데이트하세요.

## 참고
GitHub Pages는 정적 웹사이트 호스팅이므로 이 게임에 서버는 필요하지 않습니다. 플레이 기록은 서버로 전송되거나 저장되지 않습니다.
