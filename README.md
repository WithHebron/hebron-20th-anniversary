# 생명을 향한 여정 — 헤브론의료원 20주년 인터랙티브 게임

## 구성 파일
- `index.html`: 게임 화면과 선택형 스토리 전체
- `cambodia-crossroads.png`: 캄보디아 농촌 갈림길 배경 이미지

## 게임 특징
- 선택지 폼이 아니라 배경 속 갈림길 표지판을 누르는 방식
- 캄보디아 농촌 풍경과 캐릭터를 중심으로 구성
- 5단계 선택에 따라 상황 설명이 바뀌는 스토리
- 모바일과 데스크톱 반응형
- 서버/DB/외부 라이브러리 없이 GitHub Pages에서 실행
- 플레이 데이터는 저장하거나 전송하지 않음

## GitHub Pages 배포
1. 새 GitHub 저장소 생성
2. `index.html`과 `cambodia-crossroads.png`를 저장소 최상위에 업로드
3. Settings → Pages → Deploy from a branch
4. `main` 브랜치와 `/ (root)` 선택 후 저장
5. 생성된 GitHub Pages 주소로 접속

배경 이미지 파일과 HTML 파일은 반드시 같은 폴더(저장소 최상위)에 있어야 합니다.
