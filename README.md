# HEBRON QUEST — 생명을 향한 여정 (업그레이드 버전)

서버와 데이터베이스 없이 GitHub Pages에서 실행되는 5개 챕터 인터랙티브 스토리 게임입니다.

## 배포
1. ZIP 압축을 풉니다.
2. `index.html`, `css`, `js` 폴더를 GitHub 저장소 최상위(root)에 업로드합니다.
3. 저장소의 **Settings → Pages → Deploy from a branch**를 선택합니다.
4. Branch는 `main`, 폴더는 `/ (root)`로 설정하고 Save를 누릅니다.
5. 생성된 GitHub Pages 주소에서 게임을 확인합니다.

## 조작
- 키보드 `←` / `→` 또는 화면 버튼: 캐릭터 이동
- `SPACE` / `ENTER` 또는 대화 버튼: 대화 진행
- 대화가 끝나면 선택지를 눌러 스토리를 진행
- 상단 사운드 버튼: 분위기음·효과음·한국어 브라우저 음성 켜기/끄기
- 초기화: 현재 브라우저에 저장된 게임 기록 삭제

## 포함 기능
- 5개 챕터, 챕터 잠금 해제, 미션·경험치·레벨·배지
- CSS로 구성한 픽셀풍 배경과 캐릭터, 움직이는 구름, 이동 애니메이션
- 모바일 화면 대응
- LocalStorage 진행 저장
- Web Audio API 효과음·분위기음 및 기기 내장 음성(TTS)

## 유의사항
- 기록은 같은 브라우저·기기에 저장되며 기기 간 동기화되지 않습니다.
- 브라우저 정책상 사운드는 사용자가 버튼을 눌러 켠 뒤 재생됩니다.
- 음성은 브라우저와 기기에 설치된 한국어 음성 엔진에 따라 달라집니다.
- 본 스토리는 전시용 가상 시나리오입니다. 실제 진료 절차·비용·의료 서비스 설명으로 사용하기 전 HMC 확인이 필요합니다.
- 현재 픽셀풍 그래픽은 CSS 도형 기반입니다. 실제 픽셀 아트 원화·캐릭터 스프라이트와 크메르어 현지 음성은 별도 제작 단계입니다.
