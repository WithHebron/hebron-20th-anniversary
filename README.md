# HEBRON QUEST — 생명을 향한 여정
서버와 데이터베이스 없이 GitHub Pages에서 실행되는 픽셀풍 인터랙티브 스토리 게임.

## 배포
1. ZIP 압축을 풉니다.
2. `index.html`, `css`, `js`를 GitHub 저장소 최상위(root)에 업로드합니다.
3. Settings → Pages → Deploy from a branch → `main` → `/ (root)` → Save.
4. 표시되는 GitHub Pages 주소로 접속합니다.

## 조작
- 방향키 ← → 또는 화면 버튼: 캐릭터 이동
- SPACE / ENTER 또는 대화 버튼: NPC 대화 및 상호작용
- 상단 사운드 버튼: 자연 분위기음, 효과음, 한국어 브라우저 음성 ON/OFF
- 처음부터: 저장 기록 초기화

## 저장과 사운드
진행도, XP, 배지는 브라우저 LocalStorage에 저장됩니다. 같은 브라우저에서만 유지되며 기기 간 동기화는 되지 않습니다. 브라우저 자동재생 정책상 사운드는 관람객이 ON 버튼을 누른 후 활성화됩니다. 자연음과 효과음은 Web Audio API로 생성하고 대화는 기기의 한국어 TTS 기능을 사용합니다. 실제 음성 품질은 브라우저와 기기 설정에 따라 다릅니다.

※ 스토리는 전시용 가상 시나리오입니다. 실제 진료 절차나 비용을 설명하는 공식 자료로 사용하기 전 HMC 확인이 필요합니다.
