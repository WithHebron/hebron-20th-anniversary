# HEBRON QUEST · 20th Anniversary Edition

GitHub Pages에서 별도 서버 없이 실행할 수 있는 정적 웹 게임입니다.

## 구성
- Hybrid 메인 화면: 20주년 인트로 + 플레이 화면 + 진행 대시보드
- Illustration 그래픽: 캄보디아 마을, 갈림길, 의료원 장면 일러스트
- Codédex 스타일: 5개 챕터, 미션, XP, 레벨, 배지, 잠금 해제
- 인터랙티브 스토리: 선택에 따라 보상과 엔딩의 선택 기록 반영
- Local 진행 저장: 브라우저 `localStorage`
- 오디오: 자연 앰비언스(브라우저 생성), 효과음(Web Audio API), 음성 안내(SpeechSynthesis)
- 반응형: 데스크톱/모바일 화면 지원

## GitHub Pages 배포
1. ZIP 압축을 풉니다.
2. 저장소 루트에 `index.html`, `css/`, `js/`, `assets/`를 업로드합니다.
3. GitHub 저장소의 **Settings → Pages**에서 배포 브랜치와 `/ (root)`를 선택합니다.
4. 저장 후 제공되는 Pages 주소로 접속합니다.

## 오디오 안내
브라우저 정책상 오디오는 사용자가 오디오 설정에서 직접 켜야 합니다.
자연 환경음과 효과음은 Web Audio API로 생성됩니다. 음성 안내는 기기/브라우저의 설치 음성을 이용하므로 한국어/크메르어 지원 여부와 발음 품질이 기기마다 다릅니다. 실제 녹음된 현지 음성 파일은 포함되어 있지 않습니다.

## 진행 데이터
진행 상황은 같은 브라우저의 localStorage에 저장됩니다. 다른 기기/브라우저와 자동 동기화되지 않습니다. 브라우저 저장 데이터를 삭제하면 진행 기록도 사라질 수 있습니다.

## 콘텐츠 주의
게임의 스토리는 체험형 전시를 위한 예시 서사입니다. 의료원의 실제 연혁·통계·인물·진료 사례를 사실로 주장하지 않습니다. 실제 20주년 연혁 자료와 사진이 확정되면 해당 콘텐츠로 교체할 수 있습니다.
