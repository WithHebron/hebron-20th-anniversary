# 생명을 향한 여정 — 2D 횡스크롤 스타일 게임 프로토타입

- `index.html` 하나로 실행됩니다.
- 장면 배경, 캐릭터, NPC, 말풍선, HUD, 선택지 표지판을 배치했습니다.
- 선택에 따라 오토바이/버스 이동 애니메이션과 다음 장소로 화면 전환이 일어납니다.
- 캄보디아 농촌 → 이동 중 → HMC 접수 → 진료실 → 치료 이후의 5개 장면입니다.
- 금액과 게임 내 시간이 선택에 따라 변합니다.
- 서버, 데이터베이스, 외부 라이브러리 없이 GitHub Pages에서 실행됩니다.

## 배포
저장소 최상위(root)에 `index.html`을 업로드하고 Settings → Pages → Deploy from a branch → `main` / `/ (root)`를 선택하세요.

스토리는 전시용 가상 시나리오입니다. 실제 진료 절차와 비용은 HMC 확인 후 수정하세요.
